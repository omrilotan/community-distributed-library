# Security

Found a security problem? Please report it privately, on GitHub:
**[Report a vulnerability](https://github.com/omrilotan/community-distributed-library/security/advisories/new)**
(the repository's **Security** tab, then **Report a vulnerability**). Only the maintainers see it, and
you can follow the report and its fix there.

Please do not open a public issue for it, or talk about it in public, until it is fixed. Every
library runs this code, and many of them are real neighbourhoods.

## What helps

- What you found, and what it lets someone do.
- How to see it happen: the steps, a request, or a small script.
- Which part it is in: core and its `/v1` API, the web app, the MCP server, email and push, or the
  setup scripts.

## What counts

The code in this repository and the documents that tell operators how to run it. A problem in one
library's own setup, such as its domain or its Cloudflare account, belongs to that library's operator,
but report it here if the code or the guide led to it.

There is one version: `main`. Every fix goes there and is deployed from there.
